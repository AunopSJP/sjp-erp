# ใบคำถามสำรวจ workflow แต่ละแผนก

ใช้ยืนยันสมมติฐานใน `GLOSSARY.md` และ `docs/adr/0001-service-contract-as-master-record.md`

## วิธีถาม

- ขอให้เล่า **งานล่าสุดที่เกิดขึ้นจริง** ทีละขั้น แล้วค่อยถามว่ากรณีอื่นต่างไปอย่างไร
- ขอดูเอกสารหรือแบบฟอร์มที่ใช้จริง
- จดว่าใครตอบ ตอบเมื่อไร ถ้าตอบไม่ได้ให้เขียนว่า "ไม่รู้" และถามต่อว่าใครรู้
- ถ้าสองคนตอบไม่ตรงกัน ให้จดทั้งสองคำตอบ
- repo นี้เป็นสาธารณะ: อย่าใส่ชื่อลูกค้า ชื่อบุคคล เลขสัญญา หรือวงเงินจริงในไฟล์ที่จะ commit ให้เก็บคำตอบดิบไว้ใน `.scratch/` ซึ่ง git ไม่ติดตาม

## ทีมบริการ / ศูนย์รับแจ้ง

1. เคสล่าสุดที่ลูกค้าตามเรื่อง เกิดอะไรขึ้นตั้งแต่รับแจ้งจนจบ
2. ตอนนี้บอกลูกค้าเรื่องเวลาไว้อย่างไร และรู้ได้อย่างไรว่าเคสไหนช้า
3. เห็นการเตือน "เกิน SLA" ในระบบไหม ใช้ตามงานหรือเปล่า
4. หลังรับแจ้ง ติดต่อผู้แจ้งกลับเมื่อไร จดไว้ที่ไหน
5. ถือว่างานเสร็จตอนไหน เคสที่ถูกตีกลับว่ายังเสียทำอย่างไร
6. เคยต้องรออะไรบ้าง (ข้อมูล อะไหล่ ทีมภายนอก นัดช่าง) ระหว่างรอถือว่าเป็นเวลาของใคร
7. ใครกำหนดหรือเปลี่ยนความเร่งด่วน ใช้เกณฑ์อะไร

## ผู้ดูแลสัญญาบริการ

1. ขอดูสัญญาจริง 2–3 ฉบับที่ต่างกัน
2. สัญญาระบุเวลาตอบรับหรือเวลาแก้ไขไหม แยกตามความเร่งด่วนหรือเปล่า
3. นับเวลา 24x7 หรือเวลาทำการ วันหยุดใช้ชุดไหน มีข้อยกเว้นการนับเวลาไหม
4. มีสัญญาที่ไม่ได้มาจากโครงการ หรือครอบคลุมหลายโครงการ/หลายไซต์ไหม
5. ต่อสัญญาแล้วเลขที่และเงื่อนไขเปลี่ยนอย่างไร
6. ลูกค้าและไซต์เดียวกันมีสัญญาที่มีผลพร้อมกันได้ไหม
7. ใครมีสิทธิ์แก้ข้อมูลสัญญา

## จัดซื้อ

1. ใบสั่งซื้อใบล่าสุด ใครขอ ใครออก ใครเห็นชอบ ใครส่งให้ผู้ขาย
2. มีใบที่ต้องขอความเห็นชอบเพิ่มไหม ตัดสินจากอะไร
3. ผู้เห็นชอบไม่อยู่ทำอย่างไร
4. คนออกใบสั่งซื้อกับคนเห็นชอบเป็นคนเดียวกันได้ไหม เกิดขึ้นจริงหรือเปล่า

## บัญชี / การเงิน

1. ค่าใช้จ่ายใบล่าสุด ใครเบิก ใครตรวจ ใครอนุมัติ ใครจ่าย
2. วงเงินหรือประเภทค่าใช้จ่ายมีผลกับผู้อนุมัติไหม มีเอกสารระบุไหม
3. มีกรณีที่คนอนุมัติรายการของตัวเองไหม ถ้าห้าม จะมีรายการไหนไม่มีคนอนุมัติ
4. ใบแจ้งหนี้และการรับชำระ มีขั้นตอนตรวจหรืออนุมัติอะไร

## ทีมโครงการ

1. โครงการล่าสุดผ่านขั้นตอนอะไรจริง ต่างจากขั้นตอนในระบบตรงไหน
2. ขั้นไหนต้องมีคนอนุมัติหรือเซ็น เอกสารใดขาดแล้วไปต่อไม่ได้
3. ส่งมอบแล้วส่งต่อให้ทีมบริการอย่างไร

## ถามทุกแผนก

1. ตรงไหนที่งานค้างหรือต้องตามบ่อยที่สุด
2. อะไรที่ตอนนี้จดนอกระบบ (กระดาษ, Excel, LINE)
